# Independent Architecture Risk Register — Mineflayer AI Swarm

**Document:** `CLAUDE_RISK_REGISTER.md`  
**Reviewer Role:** Independent Principal Software Architect  
**Classification Scale:** `Critical` (guaranteed runtime failure, OOM, or data loss) · `High` (incorrect allocation, ledger corruption, security bypass, or multi-bot stall) · `Medium` (degraded reliability or operational friction) · `Low` (minor performance/ergonomic hazard)

## 3. Medium & Low Risks (`MED-01 .. MED-06`, `LOW-01 .. LOW-03`)

| ID | Severity | Likelihood | Affected Artefacts | Technical Failure Mode | Recommended Mitigation |
|---|---|---|---|---|---|
| **`MED-01`** | **Medium** | High | `MASTER_SPEC.md` §7 (`ai.timeoutMs = 8000`), `OllamaClient.js` | Self-hosted £0 Ollama unloads model weights after 5 min idle; cold reload from disk takes `6–20s`, triggering unnecessary `8s` timeouts on the first intent. | Split fast socket connect timeout (`2,500 ms`) from cold-inference deadline (`20,000 ms` when model cold, `8,000 ms` when warm) and pass `keep_alive: "15m"` on active sessions. |
| **`MED-02`** | **Medium** | Medium | `ARCHITECTURE.md` §2.2 (`GET /worker/v1/commands?wait_ms=25000`) | Mobile Wi-Fi / VPN NAT drops idle 25s HTTP sockets without `RST`, delaying `safe_stop` delivery. | Cap `wait_ms <= 15,000 ms`, enable TCP `keepAlive` (`10s`), and include `urgentStopBotIds` / `revokedLeaseIds` in `5s` `/worker/v1/heartbeat` responses. |
| **`MED-03`** | **Medium** | Medium | `CapabilityProfiler.js`, `TASK_ALLOCATION.md` §3 | Recording rate samples only on completed assignments ignores failed/depleted `0`-yield searches, overestimating throughput in exhausted chunks. | Record partial and failed `RESOURCE_NOT_FOUND` / `PATH_BLOCKED` attempts (`unitsCompleted / durationSec`) so `r_p10` reflects real terrain friction. |
| **`MED-04`** | **Medium** | High | `ActionExecutor.js`, `CapabilityProfiler.js`, `TASK_ALLOCATION.md` §2 | `3×3` recipes (`wooden_pickaxe`, `chest`, `furnace`) fail without a nearby `minecraft:crafting_table` or `>= 2` free inventory slots for intermediate planks/sticks. | Add `hasCraftingTableItem` / `nearbyCraftingTable` to `BotCapabilities` and auto-insert or require a crafting-table sub-step before `3×3` `craft` actions. |
| **`MED-05`** | **Medium** | High | `PERFORMANCE_PLAN.md` §1 & §6 | Samsung OneUI (Android 16) battery restrictions & `max_phantom_processes` throttle or kill Termux sockets despite `termux-wake-lock`. | Document mandatory Galaxy A06 setup checklist: Termux battery -> **Unrestricted**, Wi-Fi sleep policy -> **Never**, and Android Developer Options -> **Disable child process restrictions**. |
| **`MED-06`** | **Medium** | Medium | `DashboardServer`, `SchemaValidator.js`, `package.json` | `express@5` throws on legacy `'*'` wildcards; adding `ajv@8` (`+18–24 MiB` RSS, `new Function` codegen) duplicates handwritten validators in `AiEfficiencyController.js`. | Pin `express@5` with explicit `/{*splat}` syntax tests, and implement `SchemaValidator.js` as zero-dependency deterministic validators shared with `AiEfficiencyController.js`. |
| **`LOW-01`** | **Low** | Medium | `CapabilityProfiler.js`, `action_rate_samples` | Querying & sorting hundreds of SQLite rate rows per candidate per objective adds avoidable CPU/DB churn. | Cache decayed `(p50, p10, sampleCount)` in `BoundedCache` (`128` keys, invalidated on new sample) and prune raw rows `> 50` per `(server, dim, action, tool)`. |
| **`LOW-02`** | **Low** | Low–Medium | `src/dashboard/` vanilla JS | Rendering untrusted `rawText`, player names, or kick messages via `innerHTML` enables stored/reflected DOM XSS in operator browser. | Mandate `element.textContent` / `document.createTextNode` everywhere in dashboard JS + strict `Content-Security-Policy: default-src 'self'; script-src 'self'; object-src 'none'`. |
| **`LOW-03`** | **Low** | High | `src/cli/commands.js`, Node 22 `node:sqlite` | Node 22 prints `ExperimentalWarning: SQLite` to stderr; callers merging `2>&1` on `swarm ... --json` fail `JSON.parse`. | Keep `CLI` strictly free of `node:sqlite` imports (HTTP loopback client only, as specified) and assert clean stdout JSON in CLI integration tests. |
