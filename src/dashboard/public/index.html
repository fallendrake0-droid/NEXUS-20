Swarm Operating Modes

  • HYBRID: Default balance—shares bots across independent tasks while allowing cooperation on suitable shared objectives.
  • DISTRIBUTED: Favors giving separate ready tasks or objectives to different eligible bots.
  • SYNCHRONIZED: Focuses the swarm on the highest-priority active task, splitting work into quotas or regions when suitable.

Each bot handles one assignment at a time. The Bot Cap, connected workers, capabilities, task dependencies, and hunger/safety needs affect scheduling.
